# LDH-GD search-round budget

The default maximum consecutive failed search rounds is
`R(n) = max(3, ceil(sqrt(n)))`, where `n` is the number of coordinates.
This gives 3 rounds in 2D and 10 rounds in 100D. The tridiagonal curvature
model, bag size, kick radius, learned step scales, penalty, and 3000-update
budget are unchanged. This is an empirical heuristic.

The rule is set in `Proposed.__init__` in `saddle/algorithms/proposed.py` and
is inherited by both `LDH` and `LDHGuessed`. To override it for an experiment:

```python
algorithm = LDH(problem, problem.start("on"), seed=0, R=20)
```

`R` controls failed search rounds before probing is disabled, not total optimizer
updates. Lowercase `r` controls the kick radius and is a different parameter.

In the 100D dense random rotation with rotation seed 0, optimizer seed 0,
and an exact-saddle start, the old explicit `R=3` fails at gamma 0.1 and 0.01.
Explicit `R=10` reaches the success tests at updates 86 and 473 respectively.
The new default produces those same runs. These are seed-0 observations;
archived result files produced with R=3 remain historical results and have
not been regenerated by this change.
